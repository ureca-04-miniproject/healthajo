# 헬스장 예약 프로그램 관리 시스템 - 건강하조

## 기능 요구사항

- 예약 정원 초과 불가 — 프로그램별 최대 정원을 초과한 예약 요청은 거부한다.
- 횟수제 회원권 잔여 횟수 관리 — 잔여 횟수가 0이면 예약 불가. 횟수는 0 미만으로 내려가지 않는다. 예약 시 차감, 취소 시 복구 여부는 별도 결정 필요.
- 동일 프로그램 중복 예약 불가 — 같은 사용자가 같은 프로그램에 2번 이상 예약할 수 없다.
- 기간제 프로그램 날짜 중복 불가 — 이미 예약한 기간제 프로그램과 날짜가 겹치는 프로그램에는 예약할 수 없다.
- 취소 가능 기간 외 취소 불가 — 프로그램에 설정된 취소 마감일이 지난 예약은 사용자가 직접 취소할 수 없다.

#### 인증

- 사용자 — 전화번호 입력.
- 관리자 — 관리자 코드(고정 비밀번호) 입력.
- 로그인 후 역할(USER / ADMIN)에 따라 화면 분기

#### 관리자

1. 회원 관리 (등록, 조회, 수정, 삭제)
    - 등록 항목: 이름, 전화번호, 회원권 (횟수제), 잔여 횟수 또는 만료일
    - 수정: 이름·전화번호·회원권 정보 변경 가능
    - 삭제: 예약 이력이 있는 회원 삭제 시 처리 정책 결정 필요 (예약 함께 삭제 vs. 삭제 불가)
    - 회원권 현황 조회 및 횟수 수동 조정(충전) 포함
2. 프로그램 관리 (등록·조회·수정·삭제)
    1. 등록 항목
        - 프로그램 이름, 상세 설명
        - 유형 선택:  횟수제(최대 이용 횟수)
        - 예약 정원
        - 예약 가능 기간 (예약을 받을 수 있는 기간)
        - 예약 취소 가능 기간 (취소 마감일)
    2. 수정: 이름·설명·정원·기간 변경 가능. 유형(기간제↔횟수제) 변경은 불가 처리 권장
    3. 삭제: 예약이 1건 이상 존재하는 프로그램 삭제 정책 결정 필요
        1. 예약 생기면 삭제 가능? 불가능?
3. 예약 관리
    - 프로그램별 예약자 목록 조회: 예약자 이름, 예약 신청일, 회원권 종류, 예약 상태
    - 관리자 강제 취소: 취소 가능 기간 무관, 횟수 복구 적용, cancelled_by = ADMIN 기록
4. 회원권 관리
    - 회원권 발급: 회원 선택 후 회원권명, 유형(COUNT / PERIOD), 총 횟수 ~~또는 만료일 입력~~
    - 특정 프로그램 전용권 발급: program_id 지정 (NULL이면 범용권)
    - 회원권 목록 조회: 회원별 보유 회원권, 상태(ACTIVE / EXPIRED) 표시
    - 횟수 수동 충전: 잔여 횟수 증가, EXPIRED이면 ACTIVE로 전환
    - 만료일 연장: PERIOD 타입 회원권 만료일 변경
5. 스케줄 관리
    - 스케줄 등록: 프로그램 선택 후 유형 선택
        - FIXED_WEEKLY: 운영 기간(시작일~종료일), 기본 정원, 요일별 시작/종료 시각 설정
        - FREE_SLOT: 운영 기간, 슬롯 시작/종료 시각, 슬롯 단위(분), 기본 정원 설정
        - EVENT: 단일 날짜, 시작/종료 시각, 정원 설정
    - 스케줄 등록 시 세션 자동 일괄 생성 (운영 기간 × 요일 / 슬롯 단위 계산)
    - 스케줄 수정: 운영 기간, 정원 변경 가능 (세션 이미 생성된 경우 이후 세션에만 적용)
    - 스케줄 삭제: 예약 0건인 경우만 허용
6. **세션 관리**
    - 세션 목록 조회: 프로그램별 날짜 / 시각 / 정원 / 예약 수 / 강사 / 상태 표시
    - 세션 강사 배정 / 변경
    - 세션 개별 취소: status = CANCELLED 처리, 해당 세션 예약자 전체 예약 자동 취소 + 횟수 복구
    - 세션 정원 개별 변경

#### 사용자

1. 예약 프로그램 목록 조회
    - 표시 항목: 프로그램 이름, 유형(기간제/횟수제), 예약 가능 여부, 잔여 정원
2. 예약 프로그램 상세 조회 (신청 현황, 프로그램 정보)
    - 표시 항목: 이름, 상세 설명, 유형, 기간 또는 제공 횟수, 정원, 현재 신청자 수, 취소 마감일
3. 예약 신청
    - 예약 가능 기간 외 신청 불가
    - 예약 유효성 검사
        - membership.status = ACTIVE 확인
        - COUNT 타입: remaining_count >= 1 / PERIOD 타입: expires_at >= 오늘
        - 회원권 전용 프로그램 일치 여부 확인
        - session.status = OPEN 확인
        - session.booked_count < session.capacity (정원 여유) 확인
        - 동일 (user_id, program_id) CONFIRMED 예약 존재 여부 확인 (프로그램 중복 신청 방지)
        - 동일 날짜 + 시간 겹치는 CONFIRMED 세션 존재 여부 확인 (시간대 중복 방지)
    - 예약 확정 시 COUNT 타입 → remaining_count 1 차감
    - remaining_count = 0이 되면 membership.status = EXPIRED 자동 전환
    - 예약 완료 후 내 예약 현황에 즉시 반영
4. 예약 취소
    - 취소 가능 기간 내에만 취소 허용
    - 취소 시 COUNT 타입 → remaining_count 1 복구
    - remaining_count 복구 후 EXPIRED이면 ACTIVE로 전환
    - cancelled_by = USER 기록
5. 내 예약 현황 확인
    - 표시 항목: 프로그램 이름, 예약 상태(예약 중/취소됨), 예약 날짜 또는 기간
    - 취소 가능한 예약에만 취소 버튼 활성화
6. 내 회원권 현황
    - 보유 회원권 목록 조회: 회원권명, 유형, 상태, 잔여 횟수 또는 만료일 표시

### 데이터 제약 조건

- reservations: UNIQUE(user_id, program_id, status) → 프로그램 중복 신청 DB 레벨 차단
- sessions: session_date + start_time ~ end_time 시간 충돌 쿼리 → 애플리케이션 레벨 처리
- memberships: COUNT 타입은 total_count / remaining_count NOT NULL
- users.deleted_at IS NOT NULL인 회원은 로그인 불가
- instructors.status = INACTIVE인 강사는 신규 세션 배정 불가

#### 프로그램 종류

- 스피닝
- 요가
- 필라테스
- 골프

#### 테이블 구조

- 사용자 테이블
- 예약 테이블
- 프로그램 테이블

# Flow

## 1. 사용자

### 생성

1. 관리자가 `사용자 관리` 화면 진입
2. 우측 상단 `사용자 추가` 버튼 클릭 → 등록 모달 오픈
3. 모달에서 입력
    - 이름 (필수)
    - 전화번호 (필수, 중복 체크)
    - 이메일 (선택)
4. `생성` 클릭
    - 성공 → 모달 닫힘, 목록 새로고침, 성공 토스트 표시
    - 실패 (중복 전화번호 등) → 모달 유지, 인라인 에러 메시지 표시
5. `취소` 또는 `X` 클릭 → 모달 닫힘, 입력값 초기화

### 조회

1. 관리자가 `사용자 관리` 화면 진입
2. 전체 사용자 목록 테이블 표시 (이름, 전화번호, 이메일, 보유 회원권 수, 등록일)
3. 검색창에 이름 또는 전화번호 입력 → 실시간 필터링
4. 특정 사용자 행 클릭 → 상세 모달 오픈
    - 기본 정보 탭: 이름, 전화번호, 이메일
    - 회원권 탭: 보유 회원권 목록, 상태, 잔여 횟수 / 만료일
    - 예약 이력 탭: 예약한 프로그램, 날짜, 상태

### 수정

1. 사용자 상세 모달에서 `수정` 버튼 클릭 → 입력 필드 활성화
2. 이름, 전화번호, 이메일 수정
3. `저장` 클릭
    - 성공 → 필드 비활성화, 변경값 반영, 성공 토스트
    - 실패 → 인라인 에러 표시
4. `취소` 클릭 → 변경사항 롤백, 필드 비활성화

### 삭제

1. 관리자가 `사용자 관리` 화면에서 목록 조회
2. 삭제할 사용자 체크박스 선택 (다중 선택 가능)
3. 1명 이상 선택 시 `삭제` 버튼 활성화
4. `삭제` 클릭 → 확인 다이얼로그 표시
    - "선택한 N명의 사용자를 삭제하시겠습니까? 예약 이력은 보존됩니다."
5. `확인` 클릭 → 논리 삭제(deleted_at 기록), 목록에서 제거, 성공 토스트
6. `취소` 클릭 → 다이얼로그 닫힘, 선택 유지

## 2. 회원권

- 회원권 테이블은 예약 가능 여부와 횟수 차감 / 복구를 담당

1. 사용자가 프로그램 예약 신청 버튼 선택한다.

(사용자 ID로 활성화된 회원권 조회) → (회원권 상태가 ACTIVE인지 확인) → (remaining_count가 1 이상인지 확인) → ( 프로그램 정원이 남아 있는지 확인) → (같은 프로그램을 이미 예약했는지 확인)

1. 신청 클릭
    - 성공 →
    - 실패 → 인라인 에러 표시

(membership.remaining_count를 1 차감) → (remaining_count가 0이면 membership.status를 EXPIRED로 변경)

- ACTIVE  : 사용 가능
- EXPIRED : 잔여 횟수 0, 사용 불가

#### 회원권 차감

먼저 등록(수강신청)한 프로그램 시간표가 떠있고 / 예약 할 수 있는 프로그램도 떠있음(상의 필요)

→ 그다음에 출석하기 누른다음에 선택

### 일괄 발급 (관리자 수동)

1. 관리자가 `프로그램 관리` → 대상 프로그램 선택 → `회원권 일괄 발급` 버튼 클릭
    - 프로그램 시작일 당일 또는 이후에만 버튼 활성화
    - 이미 발급 완료된 경우 버튼 비활성화 + "발급 완료" 표시
2. 확인 다이얼로그
    - "CONFIRMED 상태 예약자 N명에게 회원권을 발급하시겠습니까?"
    - 발급될 회원권 정보 미리보기: 회원권명, 총 횟수
3. `확인` 클릭 → 일괄 처리
    - CONFIRMED 예약자 전원 대상으로 membership 행 생성
        - program_id = 해당 프로그램 ID
        - name = "{프로그램명} 수강권"
        - type = COUNT
        - total_count = 해당 프로그램 총 세션 수
        - remaining_count = total_count
        - status = ACTIVE
    - 각 reservation.membership_id 업데이트
    - reservation.status = MEMBERSHIP_ISSUED 로 변경
4. 성공 토스트 "N명 회원권 발급 완료"

### 횟수 수동 조정 (관리자)

1. 관리자가 `회원 관리` → 회원 상세 → `회원권` 탭에서 대상 회원권 선택
2. `횟수 수정` 버튼 클릭 → 수정 모달
    - 현재 잔여 횟수 표시
    - 조정할 횟수 입력 (양수: 충전 / 음수: 차감)
    - 조정 후 잔여 횟수 미리보기 표시
3. `저장` 클릭
    - remaining_count 업데이트
    - remaining_count > 0이고 EXPIRED이면 → ACTIVE 전환
    - remaining_count = 0이면 → EXPIRED 전환
    - 성공 토스트

### 세션 수강 처리 (관리자)

1. 관리자가 `세션 관리` → 해당 세션 선택 → 수강자 목록 조회
2. 출석한 수강자 체크박스 선택
3. `수강 처리` 버튼 클릭 → 확인 다이얼로그
    - "선택한 N명의 횟수를 차감하시겠습니까?"
4. `확인` 클릭
    - 대상 회원권 remaining_count -1
    - remaining_count = 0이면 → EXPIRED 전환
    - 성공 토스트

### 회원권 (사용자 화면)

### 내 회원권 현황 조회

1. 사용자가 로그인 후 `내 회원권` 탭 진입
2. 보유 회원권 목록 표시
    - 회원권명
    - 연결된 프로그램명
    - 상태 (ACTIVE / EXPIRED)
    - 총 횟수 / 잔여 횟수
    - 잔여 횟수 시각화 (예: 10회 중 7회 남음 → 프로그레스 바)
    - 발급일
3. EXPIRED 상태 회원권은 목록 하단에 회색으로 표시

### 횟수 사용 이력 조회

1. `내 회원권` 탭에서 특정 회원권 클릭 → 상세 모달
2. 횟수 사용 이력 표시
    - 세션 날짜 / 시각
    - 프로그램명
    - 처리 유형 (수강 / 취소 복구 / 관리자 조정)
    - 변동 횟수 (-1 / +1 / +N)
    - 처리 후 잔여 횟수

## 3. 프로그램

### 생성

1. 관리자가 `프로그램 관리` 화면에서 `프로그램 추가` 클릭
2. 프로그램 기본 정보 입력
    - 프로그램명 (필수)
    - 종목 선택: SPINNING / YOGA / PILATES / GOLF (필수)
    - 상세 설명
    - 예약 가능 기간: 시작일 ~ 종료일 (필수)
    - 취소 가능 기간: 시작일 ~ 종료일 (필수)
3. `다음` 클릭 → 스케줄 설정 단계
    - 운영 기간, 기본 정원 입력 → 요일 추가 버튼으로 요일별 시작/종료 시각 입력 (여러 요일 추가 가능)
4. `생성` 클릭
    - 성공 → 스케줄 기반으로 세션 일괄 자동 생성, 프로그램 목록으로 이동, 성공 토스트
    - 실패 → 인라인 에러 표시
5. `취소` 클릭 → 프로그램 관리 화면으로 이동, 입력값 초기화

### 조회

1. 관리자가 `프로그램 관리` 화면 진입
2. 프로그램 목록 테이블 표시 (프로그램명, 종목, 스케줄 유형, 예약 기간, 총 정원, 현재 예약 수, 상태)
3. 종목 / 스케줄 유형 필터 적용 가능
4. 프로그램 행 클릭 → 상세 화면 진입
    - 기본 정보 탭: 프로그램 정보, 스케줄 정보
    - 세션 탭: 날짜별 세션 목록, 예약 수, 강사, 상태
    - 예약자 탭: 전체 예약자 목록

### 수정

1. 프로그램 상세 화면에서 `수정` 버튼 클릭
2. 수정 가능 항목
    - 프로그램명, 설명 변경 가능
    - 예약 가능 기간, 취소 가능 기간 변경 가능
    - 스케줄 운영 기간, 정원 변경 가능 (이미 생성된 세션 중 미래 세션에만 반영)
    - 종목 변경 불가 (비활성화)
3. `저장` 클릭 → 성공 토스트, 상세 화면 갱신
4. `취소` 클릭 → 변경사항 롤백

### 삭제

1. 프로그램 목록에서 삭제할 프로그램 체크박스 선택
2. `삭제` 클릭
    - 예약 1건 이상 존재 시 → "예약자가 존재하여 삭제할 수 없습니다" 안내 후 중단
    - 예약 0건 → 확인 다이얼로그 "프로그램을 삭제하시겠습니까?"
3. `확인` 클릭 → 프로그램 및 연결된 스케줄 / 세션 함께 삭제, 목록 갱신

## 4. 예약 (사용자 화면)

### 예약 신청

1. 사용자가 로그인 후 `프로그램 목록` 화면 진입
2. 프로그램 카드에서 예약 가능 여부, 잔여 정원 확인
3. 원하는 프로그램 클릭 → 프로그램 상세 화면 진입
4. 세션 목록에서 원하는 날짜 / 시각 선택
    - 잔여 정원 0인 세션은 비활성화
    - 이미 예약한 세션은 "예약 완료" 표시
5. `예약 신청` 버튼 클릭 → 유효성 검사 실행 (회원권 무관)
    - ① session.status = OPEN 여부
    - ② session.booked_count < session.capacity (정원 여유)
    - ③ 동일 프로그램 중복 신청 여부 (같은 program_id로 CONFIRMED 예약 존재)
    - ④ 동일 날짜 + 시간 겹치는 다른 세션 CONFIRMED 예약 여부 검사 통과 → 예약 확정
    - reservation.status = CONFIRMED
    - session.booked_count +1
    - 성공 토스트 표시 검사 실패 → 실패 사유 안내
    - "정원이 초과되었습니다"
    - "이미 예약한 프로그램입니다"
    - "해당 시간대에 다른 예약이 있습니다"

### 예약 취소 — 프로그램 시작 전

1. 사용자가 `내 예약 현황`에서 취소 가능 기간 내 예약 확인
2. `취소` 클릭 → 확인 다이얼로그
    - "예약을 취소하시겠습니까? 프로그램 시작 전이므로 회원권은 발급되지 않습니다."
3. `확인` 클릭
    - reservation.status = CANCELLED, cancelled_by = USER
    - session.booked_count -1
    - 회원권 미발급 상태이므로 횟수 복구 없음

### 예약 취소 — 프로그램 시작 후

1. 사용자가 `내 예약 현황`에서 취소 가능 기간 내 예약 확인
2. `취소` 클릭 → 확인 다이얼로그
    - "예약을 취소하시겠습니까? 사용하지 않은 잔여 횟수는 유지됩니다."
3. `확인` 클릭
    - reservation.status = CANCELLED, cancelled_by = USER
    - session.booked_count -1
    - 발급된 회원권은 유지 (잔여 횟수 복구 없음 — 이미 프로그램이 진행 중이므로)

### 예약 취소 (관리자 강제)

1. 관리자가 `예약 관리` 화면 → 프로그램 선택 → 예약자 목록 조회
2. 강제 취소할 예약자 선택
3. `강제 취소` 클릭 → 확인 다이얼로그
    - "강제 취소 시 잔여 횟수가 복구됩니다."
4. `확인` 클릭 → 취소 처리
    - reservation.status = CANCELLED, cancelled_by = ADMIN
    - COUNT 타입: remaining_count 1 복구, EXPIRED이면 ACTIVE 전환
    - 성공 토스트

## 5. 세션 (관리자 화면)

### 강사 배정

1. 프로그램 상세 → 세션 탭에서 특정 세션 선택
2. `강사 배정` 클릭 → 활성 강사 목록 드롭다운 표시
3. 강사 선택 후 `저장` → 세션에 instructor_id 업데이트

### 세션 개별 취소

1. 세션 탭에서 취소할 세션 선택
2. `세션 취소` 클릭 → 확인 다이얼로그
    - "해당 세션의 예약자 N명의 예약이 자동 취소되고 횟수가 복구됩니다."
3. `확인` 클릭
    - session.status = CANCELLED
    - 해당 세션 전체 예약자 reservation.status = CANCELLED, cancelled_by = ADMIN
    - COUNT 타입 회원권 보유자 전원 remaining_count 1씩 복구

## 6. 출석 관리 (사용자)

### 출석 가능 세션 자동 식별

- 사용자가 로그인하면 현재 시각 기준으로 출석 가능한 세션 자동 조회
    - 조건: session_date = 오늘 AND start_time <= 현재시각 <= end_time
    - 조건: 해당 세션에 CONFIRMED 또는 MEMBERSHIP_ISSUED 상태 예약 존재
    - 조건: reservation.attendance_status = PENDING
    - 조건: membership.status = ACTIVE AND remaining_count >= 1
- 위 조건 충족 시 메인 또는 내 예약 현황 상단에 출석 가능 세션 배너 노출
    - 표시 항목: 프로그램명, 세션 시작/종료 시각, 잔여 횟수, 출석 버튼

### 출석 처리

- 출석 버튼 클릭 → 확인 다이얼로그
    - "출석 처리 하시겠습니까? 잔여 횟수가 1회 차감됩니다."
- 확인 시 처리
    - reservation.attendance_status = ATTENDED
    - reservation.attended_at = 현재 시각
    - membership.remaining_count -1
    - remaining_count = 0이면 membership.status = EXPIRED
    - membership_histories 기록: change_type = USE, session_id = 해당 세션
- 출석 완료 후 버튼 사라지고 "출석 완료" 표시

### 출석 버튼 비활성화 조건

- 현재 시각이 세션 시간대 밖인 경우
- attendance_status = ATTENDED 또는 ABSENT인 경우 (이미 처리됨)
- membership.remaining_count = 0인 경우
- 회원권 미발급(reservation.membership_id = NULL)인 경우

## 6. 출석 관리 (관리자 화면)

### 출석 관리 화면 진입

- 관리자 메뉴에 출석 관리 탭 독립 항목으로 추가
- 진입 시 오늘 날짜 기준 세션 목록 기본 표시
- 날짜 필터로 과거 날짜 조회 가능 (소급 처리 목적)
- 프로그램 / 종목 필터 적용 가능

### 세션별 출석 현황 조회

- 세션 행 클릭 → 해당 세션 예약자 목록 상세 조회
- 표시 항목
    - 예약자 이름
    - 전화번호
    - 회원권명
    - 잔여 횟수 (처리 전 현재값)
    - 출석 상태 (PENDING / ATTENDED / ABSENT)
    - 출석 처리 일시
    - 처리 주체 (본인 직접 / 관리자)
- 회원권 미발급(membership_id = NULL) 예약자는 별도 표시 — 출석 처리 불가

### 출석 처리

- 세션 시간대 내(start_time ~ end_time) 또는 지난 세션 모두 처리 가능
- PENDING 상태 예약자 체크박스 선택 (다중 선택 가능)
- 출석 처리 버튼 클릭 → 확인 다이얼로그
    - 현재 세션: "선택한 N명을 출석 처리하시겠습니까? 잔여 횟수가 차감됩니다."
    - 지난 세션: "지난 수업에 대해 출석 처리하시겠습니까? 잔여 횟수가 차감됩니다."
- 확인 시 처리
    - reservation.attendance_status = ATTENDED
    - reservation.attended_at = 현재 시각
    - membership.remaining_count -1
    - remaining_count = 0이면 membership.status = EXPIRED
    - membership_histories 기록: change_type = USE, session_id = 해당 세션
- 처리 완료 즉시 목록 갱신 (출석 수 + 미처리 수 업데이트)

### 결석 처리

- 세션 종료 후(end_time 경과)에만 결석 처리 버튼 활성화
- PENDING 상태 예약자 선택 → 결석 처리 버튼 클릭 → 확인 다이얼로그
    - "선택한 N명을 결석 처리하시겠습니까? 횟수는 차감되지 않습니다."
- 확인 시 처리
    - reservation.attendance_status = ABSENT
    - 횟수 차감 없음
    - membership_histories 기록 없음

### 출석 처리 취소

- ATTENDED 상태 예약자 선택 → 출석 취소 버튼 클릭
- 처리 당일에 한해서만 취소 가능
    - 조건: reservation.attended_at의 날짜 = 오늘
- 확인 다이얼로그
    - "출석을 취소하시겠습니까? 잔여 횟수가 복구됩니다."
- 확인 시 처리
    - reservation.attendance_status = PENDING
    - reservation.attended_at = NULL
    - membership.remaining_count +1
    - EXPIRED이면 ACTIVE 전환
    - membership_histories 기록: change_type = CANCEL_RESTORE

### 출석 처리 완료 잠금

- 세션 출석 처리를 모두 마친 후 관리자가 출석 마감 버튼 클릭
- 확인 다이얼로그
    - "출석을 마감하시겠습니까? 마감 후에는 수정이 불가합니다."
    - 미처리 인원이 남아 있을 경우 추가 경고: "미처리 인원 N명이 있습니다. 계속하시겠습니까?"
- 확인 시 처리
    - session.attendance_closed = 1
    - session.attendance_closed_at = 현재 시각
    - 이후 해당 세션 출석/결석/취소 버튼 전체 비활성화
