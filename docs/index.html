Topic

무엇을, 왜 만들었나요?

스피닝·요가·필라테스·골프 프로그램의 예약과 운영을 하나의 흐름으로 묶은 헬스장 통합 관리 시스템

🔍 Problem · 문제

프로그램·정원·회원권·취소 규칙이 서로 얽혀 있어, 수기·엑셀 관리로는 중복 예약·정원 초과·횟수 오차가 잦고 추적이 어렵습니다.

→
✨ Solution · 해결

예약 → 회원권 차감 → 세션 → 출석까지 한 흐름으로 자동화하고, 관리자·사용자 역할을 분리한 데스크톱 앱으로 풀었습니다.

🎯

정원✓중복✓ 시간✓마감✓
